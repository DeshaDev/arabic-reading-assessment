# 👁️ منصة القارئ الذكي (Smart Reader)
## التقييم المبكر لمهارات القراءة والكشف عن مؤشرات عسر القراءة بتتبع النظر بالذكاء الاصطناعي

> **منتج رقمي كامل ومبني للعمل الميداني بنسبة 100% عبر كاميرات الحواسيب والأجهزة اللوحية العادية، دون الحاجة لأي عتاد متخصص.**

---

### 🌟 الميزات الجوهرية للنظام:
1. **تتبع حركة العين على جهاز المستخدم (On-Device Computer Vision):**
   * كشف معالم الوجه والبؤبؤ مباشرة داخل المتصفح.
   * فلتر **One-Euro Filter** التكيفي لإزالة تشويش واهتزاز الكاميرا مع الحفاظ على سرعة القفزات البصرية.
   * خصوصية مطلقة: **صفر إطارات فيديو تُرفع إلى السحابة** (المعالجة بالكامل في ذاكرة الرام للمتصفح).

2. **لعبة المعايرة التفاعلية (5-Point Gamified Calibration):**
   * لعبة "النجم السحري" السريعة المصممة خصيصاً لتهيئة الأطفال خلال أقل من 30 ثانية.
   * حساب مصفوفة التحويل الرياضي التربيعي بدقة عالية.

3. **بنك النصوص العربية المعيارية (الصفوف 1 - 6):**
   * نصوص بتشكيل كامل (الصفوف 1 و 2)، وتشكيل جزئي (3 و 4)، وبدون تشكيل (5 و 6).
   * مراعاة التزاحم البصري، وتشابه الحروف (ب/ت/ث/ن/ي، ج/ح/خ)، والاتجاه من اليمين إلى اليسار (RTL).
   * أسئلة فهم مقروء لقياس الاستيعاب الحرفي والاستنتاجي.

4. **محرك تصنيف حركات العين البيومترية (I-VT Algorithm):**
   * قياس فترات التثبيت (Fixation Duration).
   * قياس سرعة القراءة الحسابية بالكلمة في الدقيقة (WPM).
   * رصد **الارتدادات العكسية (RTL Regressions)** لليمين، وهي المؤشر العصبي الأول لعسر القراءة.

5. **التمثيل البصري الفوري (Scanpath & Heatmap):**
   * رسم مسار القراءة المتسلسل مع تمييز الارتدادات باللون الأحمر وأسهم الاتجاه.
   * خريطة حرارية لتحديد الكلمات التي سببت إجهاداً أو توقفاً مطولاً للطفل.

6. **لوحة تحكم المعلم والمدرسة:**
   * إدارة الطلاب، تتبع الحالات ومؤشرات الخطر (منخفض / متوسط / مرتفع).
   * بطاقات إحصاءات عامة ومقارنة بالمعايير العمرية والصفية.

7. **تقرير ولي الأمر العربي (جاهز للطباعة والـ PDF):**
   * لغة مطمئنة وغير موصمة للأهل.
   * 3 ألعاب قراءة وتمارين منزلية عملية.
   * التزام تام بإخلاء المسؤولية: أداة فرز ومسح مبدئي وليست تشخيصاً طبياً.

8. **ألعاب التدخل والتدريب التفاعلية (Intervention Games):**
   * لعبة صائد النقاط (للحروف المتشابهة).
   * قفزات الصقر الإيقاعية (لتدريب عضلات العين).

---

### 🚀 طريقة التشغيل السريعة:
1. تشغيل الخادم المحلي:
   ```bash
   npm start
   ```
2. فتح المتصفح على العنوان:
   ```
   http://localhost:3000
   ```
