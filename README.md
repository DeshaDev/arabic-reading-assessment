# نَبراس — مختبر القراءة العربية

منصة ويب تجريبية تساعد المعلم على تنظيم جلسة قراءة عربية، تسجيل إجابات الفهم، ومراجعة مؤشرات وصفية من الجلسة. المشروع ما زال نموذجًا أوليًا، وليس منتجًا سريريًا أو أداة معتمدة للكشف عن عسر القراءة.

## ما يعمل في هذه النسخة

- لوحة RTL متجاوبة تعرض السجلات والجلسات الموجودة فعلًا في ملف البيانات، وتعرض حالة فارغة واضحة عند عدم وجود بيانات.
- إدارة سجلات الطلاب مع تحقق أساسي من الحقول والبحث والتصفية حسب الصف.
- مكتبة نصوص وأسئلة فهم عربية متدرجة للصفوف 1–6.
- تجربة جلسة: اختيار نص، محاولة معايرة خمس نقاط، قراءة محددة بالوقت، أسئلة فهم، ثم ملخص وصفي.
- رسم مسار النظر/الخريطة الحرارية داخل الجلسة الحالية عند توفر عينات كافية بعد المعايرة.
- تقرير قابل للطباعة أو الحفظ بصيغة PDF، بلغة لا تصف الطفل بأنه مصاب بعسر القراءة.
- تحقق من مدخلات API، وقيود على حجم الطلبات والقيم، وعدم تخزين إحداثيات النظر الخام في ملف JSON.

## تشغيل محليًا

يتطلب Node.js بإصدار يدعم اختبارات node:test.

~~~bash
npm install
npm start
~~~

ثم افتح http://127.0.0.1:3000.

لتشغيل اختبارات المحرك:

~~~bash
npm test
~~~

يمكن تحديد المنفذ عبر PORT والمضيف عبر HOST. افتراضيًا يستمع الخادم على 127.0.0.1 حتى لا ينكشف على الشبكة المحلية دون قصد. لا تغيّر HOST إلى 0.0.0.0 إلا إذا كنت تدرك تبعات تعريض الخادم.

## حدود مهمة قبل الاستخدام الميداني

- **لا يوجد تشخيص لعسر القراءة.** لا ينتج النظام درجة خطر تشخيصية، ولا يثبت أن الطفل لديه صعوبة تعلم أو لا يعاني منها.
- **تتبع النظر تجريبي.** تقدير اتجاه النظر عبر كاميرا ويب عادية يتأثر بالكاميرا والإضاءة ووضعية الرأس والشاشة، ولا توجد في هذا المستودع دراسة تحقق سريري تثبت صلاحيته لعسر القراءة باللغة العربية.
- **المعايرة ليست قياسًا للدقة.** إكمال نقرات نقاط المعايرة لا يعني أن دقة النظر قد تم التحقق منها علميًا.
- **سرعة القراءة ليست معيارًا منفردًا.** لا يحسب النظام السرعة إذا كانت الجلسة قصيرة جدًا أو كان الناتج خارج فحص الجودة التقني؛ ويجب تفسير النتائج في سياق تعليمي أوسع.
- **لا تستخدم بيانات أطفال حقيقية في نسخة عامة أو غير محمية.** الخادم لا يحتوي على تسجيل دخول أو صلاحيات أو تشفير للبيانات المخزنة. الأسماء والملاحظات وملخصات الجلسات تُكتب في المسار data/database.json. قبل تجربة مدرسية، يجب إضافة المصادقة والتحكم في الوصول وموافقة المدرسة/ولي الأمر وسياسة احتفاظ وحذف بيانات مناسبة.
- إحداثيات النظر الخام لا تُحفظ على الخادم، لكنها تُستخدم مؤقتًا في ذاكرة المتصفح لرسم المسار داخل الجلسة. وقد تسجل كاميرا الطفل بيانات حساسة؛ اشرح ذلك واحصل على الموافقات المناسبة.

## البنية

- server.js — Express API محلي للسجلات وملخصات الجلسات.
- public/index.html وpublic/css/style.css — واجهة RTL المتجاوبة.
- public/js/dashboard.js — اللوحة والسجلات والحالات.
- public/js/assessment.js — سير الجلسة والمعايرة والقراءة والفهم.
- public/js/tracker.js — تكامل WebGazer وإشارة الكاميرا.
- public/js/metrics.js — استخراج مؤشرات وصفية وفحوص جودة بسيطة، دون معايير تشخيصية.
- public/js/report.js — ملخص الأسرة والطباعة.
- public/js/texts.js — بنك النصوص وأسئلة الفهم.
- test/metrics.test.js — اختبارات حدود حساب سرعة القراءة وجودة الجلسة.

## النطاق التالي قبل ادعاء الجاهزية

1. مراجعة تربوية ولغوية مستقلة للنصوص وأسئلة الفهم حسب البلد والمنهج.
2. بروتوكول قياس محدد مسبقًا، ومقارنة علمية مع أدوات عربية معيارية وبيانات ممثلة، ومراجعة أخلاقية قبل أي ادعاء حول عسر القراءة.
3. بنية بيانات آمنة بهوية وصلاحيات وسجل تدقيق وإجراءات حذف ونسخ احتياطي.
4. اختبارات فعلية عبر أجهزة وكاميرات ومتصفحات متنوعة، مع قياس معدل فشل المعايرة بدل الاكتفاء بإكمال خطواتها.
